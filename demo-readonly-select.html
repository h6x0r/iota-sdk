Демонстрация Readonly Селектов

✅ Исправленные компоненты РАБОТАЕТ

Этот селект имеет атрибут disabled и применены CSS стили
Это поле имеет атрибут readonly

❌ Компоненты требующие исправления НЕ РАБОТАЕТ

Этот селект имеет только readonly атрибут - НЕ РАБОТАЕТ в HTML!
Checkbox не поддерживает readonly, нужен disabled

🔧 Решение

Для корректной работы readonly селектов нужно:

  1. В backend: передавать readonly: true в атрибутах поля
  2. В template компонентах: конвертировать readonly → disabled для select, checkbox, radio
  3. В CSS: стилизовать disabled элементы как readonly (серый фон, заблокированное взаимодействие)
  4. В форме: игнорировать readonly поля при отправке

Код для template компонентов:

// В select.templ
disabled?={ p.Attrs["readonly"] == true || p.Attrs["disabled"] == true }

// В CSS
.form-control-input[readonly], select[disabled] {
    cursor: not-allowed;
    opacity: 0.7;
    background-color: #f3f4f6;
    pointer-events: none;
}
